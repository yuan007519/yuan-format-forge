# 使用说明

适用版本 1.5.4（versionCode 12），包名 `com.fmtlab.toolbox`，Android 7.0 及以上。

所有转换在设备本地执行。APK 未申请任何权限，包括网络权限。

## 安装

Release 中有两个包，功能一致，仅内置 FFmpeg 原生库的 ABI 不同：

| 文件 | 体积 | 适用 |
|---|---|---|
| `yuan-format-forge_1.5.4_arm64.apk` | 27.0 MB | arm64-v8a 设备 |
| `yuan-format-forge_1.5.4_full.apk` | 54.4 MB | 含 armeabi-v7a，兼容旧设备 |

安装时系统会提示未知来源，允许即可。精简包装到 32 位设备会报“应用未安装”，换完整包。

签名与历史版本相同，可直接覆盖升级。

## 选择文件

所有模块的文件选择器都不按 MIME 过滤，避免 rmvb、m2ts 这类系统识别不出的扩展名被隐藏。选中后按扩展名、文件头和媒体轨道判断类型；类型不符时给出提示，不会静默跳过。

## 各模块

### 文本乱码修复

自动判断 UTF-8、GBK、Big5、Shift_JIS、EUC-KR、UTF-16（带 BOM）、Windows-1252，可还原 `锟斤拷`、`浣犲ソ` 一类乱码，支持按 6 种编码另存。

### 图片

输入：png、jpg、jpeg、jfif、jpe、webp、bmp、gif、ico、tif、tiff、tga、qoi、ppm、psd。

输出：png、jpg、webp、bmp、tiff、tga、qoi、ico、ppm。

带质量滑杆、缩放档位、EXIF 方向纠正和批量处理。系统解码器不认识的格式交给 FFmpeg 直接转换；输出 tiff、tga、qoi、ico、ppm 时先解成无损 PNG 再编码。

### PDF

五个模式：

1. PDF 转图片：png、jpg，2x / 3x / 4x 渲染，可指定页码，如 `1-3,5`。
2. 图片转 PDF：多选图片，页面可选跟随图片、A4 竖版、A4 横版。
3. PDF 转 PPTX：每页渲染成一张图片放进幻灯片，版式保留，文字不可编辑。
4. PPTX 转 PDF：有整页图片的按图片还原，纯文字幻灯片重新排版。
5. PDF 转文本：可导出 txt、md、html、docx。中文 PDF 的 CID 字体会读 ToUnicode 表还原；选 DOCX 时按 PDF 里的坐标放文字，图片和表格线也在原位，文字仍可编辑。扫描件没有文字层，或字体里取不到 Unicode 映射时，会退回每页一张图的图片版 Word。

### 文档

输入：docx、xlsx、pptx、odt、ods、odp、epub、html、htm、md、markdown、rtf、csv、tsv、json、xml、yaml、yml、txt、log。

输出：txt、md、html、docx、odt、rtf、pdf、epub、csv、tsv、json、xlsx、ods。

表格类输入（xlsx、ods、csv、tsv）可输出 xlsx、ods、csv、tsv、HTML 表格、Markdown 表格、JSON、PDF。

pptx 额外支持逐页导出 PNG、JPG：先用排版引擎生成 PDF，再按页渲染。

转换只保留文字与表格内容，多栏、SmartArt、公式、图片位置会丢失。

### 字幕

输入 srt、vtt、ass、ssa，输出 srt、vtt、ass、ssa、txt。

界面显示条数和总时长，并预览前 12 条。ASS / SSA 会去掉样式标签，`\N` 转为换行。

### 音频提取

从视频提取音轨，输出 wav、m4a、aac、mp3、flac、ogg、opus、wma。

前三种走系统解码，其余由 FFmpeg 编码。不支持音乐平台加密格式。

### 视频

输出：

- 换壳：MP4、WebM、MKV、MOV。MP4 / WebM 用系统 MediaMuxer；MKV / MOV 用 FFmpeg 流拷贝，失败时自动重编码并在界面说明。
- GIF：可选帧率、宽度、起始时间、时长（最长 60 秒），使用全局 256 色调色板。
- 抽帧：按 0.5 / 1 / 2 秒间隔导出 JPG，单次最多 60 张。
- 音轨：mp3、m4a、wav、flac、ogg、aac、opus、wma。

### 万能转码

14 种输出：MP4（H.264 / H.265）、MKV、MOV、AVI、WMV、FLV、WebM、MP3、M4A、AAC、WAV、FLAC、OGG。三档画质，显示进度和编码倍速，可取消。

### 编码工具箱

Base64、URL、HEX、Unicode 的双向编解码。

## 已知限制

- 无 OCR，图片和扫描版 PDF 不能转文字。
- 不支持相机 RAW、SVG、JXL、AVIF、heic/heif。
- 不支持 doc、wps、wpt、et、ett、dps、dpt、xls、ofd、mobi 这类旧二进制格式。
- PDF 转 XLSX、PPTX 转 ODP 没做。
- Office 文档之间转换只处理文字和表格，不保留多栏、SmartArt、公式这些版式。
- PDF 转 DOCX 按页面坐标摆放，旋转文字、跨栏排版可能对不齐；扫描件只能出图片版。
- GIF 最长 60 秒，帧率高于 20 时部分浏览器播放速度可能不准。
- 视频重编码比较慢，10 分钟 1080p 大约要 1 到 4 分钟。
