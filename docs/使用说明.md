# 袁神的格式工坊 · 使用说明

**版本 1.3（versionCode 4）｜包名 com.fmtlab.toolbox｜Android 7.0 及以上｜56.8 MB**

九大模块：文本乱码修复、图片、PDF（含 PDF ⇄ PPTX）、文档、音频、视频、万能转码、编码工具、关于与许可。
所有转换都在手机本地完成：**APK 没有申请任何权限（连联网权限都没有）**，不联网、不上传、不读与任务无关的文件。

## 二、选文件：这次不会再"漏掉"文件了

以前的版本里，选视频时用系统过滤（只显示 `video/*`），而 rmvb、m2ts、vob、f4v 这些后缀很多手机认不出来，会被系统当成"未知类型"直接隐藏，看着就像"文件不见了"。

1.3 版把七个模块的选择器都改成不过滤类型：

- 打开选择器后，任何文件都能列出来；
- 选中后应用自己判断真实类型（后缀 + 文件头 + 音视频轨道三重判断）；
- 如果选错了（比如给视频模块选了个音频），会明确提示"这个文件看着是音频（扩展名 .m4a），不是视频。仍可点开始，处理失败会给出具体原因"，而不是悄悄不显示。

这类问题在 v1.2 里的典型表现是"万能转码能看到、视频工具看不到"——同一台手机同一个文件，不同模块表现不同。遇到过这种情况的话，1.3 版可以直接解决。

## 三、视频模块

四个输出：**MP4 换壳**、**WebM 换壳**、**GIF 动图**、**抽帧图片**。

### 3.1 GIF 参数（1.3 版重做）

| 参数 | 可选项 | 说明 |
|---|---|---|
| 帧率 | 8 / 10 / 12 / 15 / 20 / 24 帧每秒 | 越高越流畅，文件也越大 |
| 宽度 | 320 / 480 / 640 / 720 px | 高度按原比例，不放大小图 |
| 起始时间 | 秒，可填小数（如 12.5） | 留空 = 从 0 秒开始 |
| 时长 | 秒，最多 60 | 留空 = 取 3 秒 |

GIF 现在由内置 FFmpeg 生成，用的是**全局 256 色智能调色板**（`palettegen` + `paletteuse` + Sierra 抖动），与 1.2 版的逐帧局部色表相比：

- 播放时不再一帧一帧闪色；
- 实拍渐变不再出网格噪点和色块；
- 截图、字幕、UI 演示类视频几乎无损；
- 单次时长上限从"120 帧"（8fps 约 15 秒）放宽到 60 秒。

### 3.2 换壳

- **MP4 换壳**：只搬轨道、不重编码，画面音质完全不变、几秒完成。适合把 mkv / mov / ts / flv / rmvb 变成更通用的 MP4。
- **WebM 换壳**：只对 VP8 / VP9 有效；H.264 的视频会提示改用 MP4。
- 遇到系统解复用器打不开的封装（RMVB / VOB / 老 AVI / WMV），会自动切到 FFmpeg：先试无损 `-c copy`，容器或编码不兼容再重编码（此时画质会有轻微变化，界面会明确写出来）。

### 3.3 抽帧

按 0.5 / 1 / 2 秒间隔导出 JPG，单次最多 60 张，长边超过 1920 自动缩小。系统解不了的封装同样会回退到 FFmpeg 抽帧。

## 四、PDF 模块（1.3 版新增 PDF ⇄ PPTX）

四种方向：

1. **PDF 转图片**：PNG / JPG，清晰度 2× / 3× / 4×，可填页码范围（如 `1-3,5`，留空为全部）。
2. **图片 转 PDF**：多选图片，页面尺寸可选"跟随图片 / A4 竖版 / A4 横版"。
3. **PDF 转 PPTX**：每页 PDF 渲染成一张高清图，生成一个"满版图片"的 PPTX。版式、字号、图表、扫描件全部保真；代价是 PPTX 里的文字不能再编辑。
4. **PPTX 转 PDF**：解析 PPTX 的幻灯片顺序，逐页处理——
   - 幻灯片里有整页图片（比如上面第 3 步生成的图片版 PPTX）→ 按原图铺满整页还原；
   - 纯文字幻灯片 → 按段落重新排版成 PDF，标题行自动加粗放大。

PDF 转 PPTX 生成的是标准 ECMA-376 包（presentation + slideMaster + slideLayout + theme + media），PowerPoint、WPS、Keynote 都能直接打开。已用 python-pptx 打开验证：3 页幻灯片、页尺寸 595×842 pt、每页一张图，结构完整；反过来，用 python-pptx 生成的真实 PPTX 也能被本应用正确读出页序、页尺寸、中英混排文字和内嵌图片。

## 七、已知限制

1. PDF 只渲染不 OCR，扫描件能出图但不识别文字。
2. PDF → PPTX 是图片版，文字不可编辑。
3. PPTX → PDF 只取每页文字和第一张图片，多图层排版、SmartArt、动画、母版装饰会简化。
4. GIF 单次最多 60 秒；帧率高于 20 时，部分浏览器对 GIF 延时精度有限，可能有轻微变速。
5. 个别设备对特殊字体或加密 PDF 的渲染会失败，应用会给出明确报错。
6. 视频转码是重编码：10 分钟 1080p 约 1–4 分钟，H.265 / VP9 更慢。
7. 本项目没有真机测试环境，硬件相关路径靠代码审查 + 桌面 JVM 单测（乱码 21/21、GIF 3/3、PPTX 读写往返 + 真实 PPTX 解析），仍有未覆盖的机型差异。
