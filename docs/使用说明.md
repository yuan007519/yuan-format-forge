# 袁神的格式工坊 v1.2 · 完整版 使用说明

一个纯本机的安卓文件格式转换工具。**内置 FFmpeg 6.0 内核**，所有转换都在手机上离线完成——不联网、不上传文件、无广告、无账号。

- 安装包：`袁神的格式工坊-1.2-完整版.apk`
- 包名 `com.fmtlab.toolbox`，版本 1.2（versionCode 3），Android 7.0 / API 24 及以上
- 体积 54.2 MB（其中约 53.9 MB 是 FFmpeg 原生库，覆盖 `arm64-v8a` 与 `armeabi-v7a` 两种 CPU）
- 升级：与之前的版本同一签名，直接覆盖安装即可，数据不丢

## 安装

1. 把 APK 传到手机（数据线、微信文件传输、QQ 均可）。
2. 点击安装；系统提示"未知来源"时允许该来源（自签名 APK 的正常提示）。
3. 打开即用，无需注册。

| # | 模块 | 能做什么 |

### 1. 文本 · 乱码复原（核心）

- 自动判断真实编码：UTF-8 / GBK / Big5 / Shift_JIS / EUC-KR / UTF-16(BOM) / Windows-1252。
- 典型场景：`锟斤拷`、`å¤`、`Ã©`、`浣犲ソ`；UTF-8 被当 GBK 读；UTF-8 被 Latin-1 读成 `cafÃ©`。
- 修复后列出候选（源编码 → 目标编码 + 可信度），点选即应用；支持逐行修复混合编码文档。
- 另存 6 种编码：UTF-8 / UTF-8 BOM / GBK / Big5 / UTF-16LE / UTF-16BE。
- 损坏过半（替换符 > 1/3）会明确提示"无法还原"，不瞎猜。

### 2. 图片

PNG / JPG / WEBP / BMP 批量互转，质量滑杆、缩放档位（原尺寸 / ≤1920 / ≤1280 / ≤800 / 50%）、EXIF 横竖纠正。

### 3. PDF

- PDF → 图片：标准 / 高清 / 超清（2× / 3× / 4×），可指定页码（`1-3,5`）。
- 图片 → PDF：跟随图片尺寸，或强制 A4 竖 / A4 横。

### 4. 文档

docx / xlsx / pptx / html / md / txt / csv → Markdown / HTML / TXT / CSV / HTML 表格，右侧实时预览。

### 5. 音频提取

视频或音频 → **WAV**（PCM）/ **M4A**（AAC 音轨直拷，不重编码）/ **AAC 裸流**（手写 ADTS 头，给剪辑软件用）。

### 6. 视频工具（v1.1）

- **MP4 换壳**：mkv / mov / ts / flv / webm 里的 H.264 / H.265 画面直接搬进 MP4，几秒、零损失。
- **WebM 换壳**：VP8 / VP9 + Opus / Vorbis 搬进 WebM。
- **GIF 动图**：8 / 12 / 15 fps，宽 320 / 480 / 640 px；≤256 色用精确调色板，多色自动 216 色 + 抖动。
- **抽帧图片**：0.5 / 1 / 2 秒间隔导出 JPG。

### 7. 万能转码（v1.2 新增，内置 FFmpeg）

选一个任意音视频文件 → 选输出格式 → 开始转码，实时显示百分比、已处理时长、实时倍速，可随时取消。

**14 种输出格式**

| 类别 | 格式 | 编码 |
|---|---|---|
| 视频 | MP4 · H.264 | libx264（兼容性最好，任何设备都能播） |
| | MP4 · H.265 | libx265 + `hvc1` tag（同画质约省一半体积） |
| | MKV | H.264 + AAC |
| | MOV | H.264 + AAC |
| | AVI | mpeg4 + MP3 |
| | WMV | wmv2 + wmav2 |
| | FLV | H.264 + AAC（44.1kHz 立体声） |
| | WebM | libvpx-vp9 + Opus |
| 音频 | MP3 / M4A / AAC / WAV / FLAC / OGG | libmp3lame / aac / aac-adts / pcm_s16le / flac / libopus… libvorbis |

**画质档位**：高清＝保留原分辨率；标准＝超过 1080 就缩到 1080；小体积＝超过 720 就缩到 720。纯音频输出时档位不生效。

**能读的输入**：AVI、WMV、RMVB、MKV、MPG、VOB、TS、FLV、MOV、MP4、3GP、WebM、OGG、M4A、WMA、APE、FLAC、AAC、MP3、WAV……FFmpeg full 版的解码器几乎全包，包括 RealVideo（RV30/RV40）。

## 使用建议

- 转码是**重新编码**，耗时与视频长度、机型有关：10 分钟 1080p → 大约 1–4 分钟。H.265 比 H.264 慢一倍左右，VP9 更慢。
- 大文件会先整份读到缓存目录再转，请预留约「源文件大小 × 2」的存储空间。
- 转码中可随时点"取消"，已产生的临时文件会自动清掉。
- 只是想换个封装（比如 mkv 转 mp4）且是 H.264 画面时，用第 6 个模块的"MP4 换壳"更快、且无损。
- 装完第一次打开会加载 FFmpeg 原生库，首页进入"万能转码"时初始化需要 1 秒左右，属正常。

## 已知限制

- PDF 只渲染不 OCR：扫描件能出图，不识别文字。
- 文档转换覆盖段落、标题、表格、文本框文字；多栏、SmartArt、公式等复杂排版会丢失。
- 字幕烧录（内嵌 SRT / ASS）未开放到界面；FFmpeg 里 libass 已编入库内，可作为后续版本。
- 开发环境无真机/模拟器，各硬件相关路径（图片解码、PDF 渲染、换壳、FFmpeg 加载）均经代码审查与桌面 JVM 单测，未做真机验证。若某模块异常，把"哪个模块 + 什么文件 + 什么提示"发回来即可针对性修。
- **许可**：`ffmpeg-kit-full-gpl` 的 `x264` / `x265` 为 GPL 许可，整包因此按 GPL v3 处理。自己用、朋友之间用没问题；若要上架应用商店或商用分发，需随包提供对应源码并遵守 GPL 条款。
- 自签名证书（`CN=FmtForge`），仅供自己安装。

## 重新构建

`袁神的格式工坊-v1.2-源码.zip` 内含完整工程（`AndroidManifest.xml`、`res/`、`src/`）、构建脚本与说明。

不依赖 Gradle：`aapt2 compile → aapt2 link → javac → jar → d8 → 塞 dex 与 so → zipalign -p → apksigner → verify`，每步都有日志。需要 JDK 17、Android SDK（`platforms;android-34` + `build-tools;34.0.0`），以及 `ffmpeg-kit-full-gpl-6.0-2.aar` 与 `smart-exception-java-0.2.1.jar`（下载地址见 zip 内 `README-构建说明.md`）。

`core/` 下的 GIF 编码器、乱码算法都是纯 Java，可在桌面 JVM 上直接单测。
