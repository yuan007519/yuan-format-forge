## 2. 解包 AAR

`Expand-Archive` 只接受 .zip 后缀，用 .NET 接口解 aar：

```powershell
Add-Type -AssemblyName System.IO.Compression.FileSystem
[IO.Compression.ZipFile]::ExtractToDirectory('ffmpeg-kit-full-gpl-6.0-2.aar', 'aar')
```

`aar/classes.jar` 是 Java 类，`aar/jni/<abi>/*.so` 是原生库。工程只打包 arm64-v8a 与 armeabi-v7a，x86 / x86_64 可省。

armeabi-v7a 的库名带 `_neon` 后缀（如 `libavcodec_neon.so`），ffmpeg-kit 的 `NativeLoader` 会在运行时按 ABI 选择，不要改名。

## 3. 构建

```
aapt2 compile      res 编译为 .flat
aapt2 link         生成 resources.ap_ 与 R.java
javac              src + R.java，classpath 含 android.jar、ffmpeg classes.jar、smart-exception.jar
jar cf             classes.jar
d8                 classes.jar + ffmpeg jars -> classes.dex
python pkg.py      写入 classes*.dex 与 lib/<abi>/*.so（so 用 STORED）
zipalign -p -f 4   4 字节对齐，so 页对齐
apksigner sign     签名
apksigner verify   校验
```

注意事项：

- `.so` 必须以 STORED 写入，否则 `zipalign -p` 无法页对齐，`System.loadLibrary` 会失败。
- `AndroidManifest.xml` 的 `<application>` 需要 `android:extractNativeLibs="true"`。
- FFmpeg 参数用 `executeWithArgumentsAsync(String[] ...)` 传数组，不要拼命令行字符串。
- PowerShell 调用 java 时编码参数要带引号：`java "-Dfile.encoding=UTF-8"`。
- 运行 `d8.bat`、`apksigner.bat` 前先设置 `$env:JAVA_HOME`。
- 不要用 PowerShell 的 `Set-Content` / `WriteAllText` 写含中文的源码，会按 ANSI 读入导致乱码；构建脚本保持 ASCII 输出。

`tools/build.ps1` 一次出两个包（全 ABI 的 `app-release.apk` 与只留 arm64 的精简包）；想只出精简包用 `tools/build-arm64.ps1`，它跳过 armeabi-v7a，由 `tools/strip64.py` 从合并后的 APK 里删掉 `lib/armeabi-v7a/`，再对齐签名。版本号写在脚本的 `aapt2 link --version-code / --version-name` 参数里，同时要把 `LicenseText.VERSION_NAME` 改成一致，否则“关于”页显示的版本会和包对不上。

## 6. FFmpeg 回调

ffmpeg-kit 6.0 的回调是 Java 8 函数式接口，抽象方法名为 `apply`：

```java
new FFmpegSessionCompleteCallback() { public void apply(FFmpegSession s) {...} }
new LogCallback()                   { public void apply(Log log) {...} }
new StatisticsCallback()            { public void apply(Statistics st) {...} }
```

`Statistics.getTime()` 返回毫秒（double），计算进度时与时长毫秒对应。`ReturnCode.isSuccess(...)`、`isCancel(...)` 是静态方法，参数可为 null。6.0 不需要 `FFmpegKitConfig.init(Context)`。
