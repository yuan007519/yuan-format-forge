# 袁神的格式工坊 · 使用说明

**版本 1.4（versionCode 7）｜包名 com.fmtlab.toolbox｜Android 7.0 及以上｜完整版 54.3 MB / 精简版 26.8 MB**

十个模块：文本乱码修复、图片、PDF、文档、字幕、音频、视频、万能转码、编码工具、关于与许可。
所有转换都在手机本地完成：**APK 没有申请任何权限（连联网权限都没有）**，不联网、不上传、不读与任务无关的文件。

**1.4 是「格式矩阵」版**：按「当前支持」清单把每个模块的输入/输出格式尽量铺开，详见第三节的对照表。

## 一、安装

Releases 里有两个安装包，功能完全一样，只是内置原生库支持的 CPU 不同：

| 文件 | 体积 | 适用机型 |
|---|---|---|
| `yuan-format-forge_1.4.0_arm64.apk` | 26.8 MB | 设置里写着 `arm64-v8a` 或「64 位」的手机，推荐 |
| `yuan-format-forge_1.4.0_full.apk` | 54.3 MB | 两种 CPU 都带；老机型或不确定时用它 |

1. 把对应版本的 APK 传到手机（数据线、微信文件传输、QQ 均可）；
2. 点击安装，系统提示"未知来源"时允许该来源（自签名 APK 的正常提示）；精简版装到 32 位机型会提示"应用未安装"，换完整版即可；
3. 打开即用，不需要注册、不需要登录。

签名证书 SHA-256：`646ee67e50f20131e315efb5d4654733da4f608173c103ae65f694597238f8b4`
签名与 1.0 起各版本一致，可以直接覆盖升级，数据不受影响。

历史版本都在 Releases 里正式发布（v1.0 / v1.1 / v1.2 / v1.3 / v1.3.1 / v1.3.2 / v1.4）：v1.2 起才内置 FFmpeg，v1.3.1 那版有闪退问题、只作回溯用，日常安装请用 **v1.4**。

## 二、选文件：不按类型过滤

1.3 起七个模块的选择器都改成不过滤类型：

- 打开选择器后，任何文件都能列出来；
- 选中后应用自己判断真实类型（后缀 + 文件头 + 音视频轨道三重判断）；
- 如果选错了（比如给视频模块选了个音频），会明确提示"这个文件看着是音频（扩展名 .m4a），不是视频。仍可点开始，处理失败会给出具体原因"，而不是悄悄不显示。

## 三、v1.4 格式对照表

### 3.1 图片

| | 格式 |
|---|---|
| 输入 | png / jpg / jpeg / jpe / jfif / webp / bmp / gif / ico / tif / tiff / tga / qoi / ppm / psd（FFmpeg 解码）；其它系统解码器认识的位图 |
| 输出 | png / jpg / webp / bmp / tiff / tga / qoi / ico / ppm |
| 参数 | 质量滑杆（JPG / WEBP / WEBP 有损）、缩放档位（原图 / 1920 / 1280 / 800 / 减半）、批量 |

实现方式：先在手机系统解码器里解（快、省电），解不开的格式（tiff / tga / qoi / psd 等）自动交给内置 FFmpeg 直转；输出 TIFF / TGA / QOI / ICO / PPM 时统一「系统解码 → 无损 PNG → FFmpeg 编码」，保证像素不被二次压缩。

### 3.2 文本（乱码修复 + 文档矩阵）

| | 格式 |
|---|---|
| 输入 | txt / log / md / markdown / html / htm / csv / tsv / json / xml / yaml / yml / **epub / odt / ods / odp / docx / xlsx / pptx** |
| 输出 | txt / md / html / json / csv / tsv / **docx / odt / rtf / pdf / epub**；表格输入另可出 **xlsx**、HTML 表格、Markdown 表格 |

- 乱码修复沿用 1.3：自动识别 UTF-8 / GBK / Big5 / Shift_JIS / EUC-KR / UTF-16(BOM) / Windows-1252，识别 `锟斤拷`、`浣犲ソ`、`Ã©` 类乱码并还原，按 6 种编码另存。
- 文档转换只做「内容级」：文字、表格、段落顺序保留；多栏、SmartArt、公式、图片位置会简化。

### 3.3 字幕（1.4 新增模块）

| | 格式 |
|---|---|
| 输入 | srt / vtt / ass / ssa |
| 输出 | srt / vtt / ass / ssa / txt |

带条数与总时长统计、前 12 条预览；ASS/SSA 会剥掉 `{...}` 样式标签、`\N` 转换行，转成 SRT 时不丢时间轴。

### 3.4 Word / WPS 文档、Excel / WPS 表格、PPT / WPS 演示

| 模块 | 输入 | 输出 |
|---|---|---|
| Word | docx / odt | pdf / docx / odt / rtf / txt / html / md / epub |
| Excel | xlsx / csv / tsv / ods | pdf / xlsx / ods（读）/ csv / html / md / json |
| PPT | pptx / odp | pdf / pptx / txt / md / html |

- DOCX 由自写 OOXML 包生成（正文 11pt、标题加粗 16pt、A4 版面、中文字体 Microsoft YaHei）；
- XLSX 由自写 SpreadsheetML 包生成（单表、内联字符串，Excel / WPS / openpyxl 均可打开，已实测）；
- ODT 由自写 OpenDocument 包生成（mimetype 按规范 STORED 首条目）；
- RTF 用 `\uN?` 转义中文，Word / WPS 可直接打开。

### 3.5 PDF

| | |
|---|---|
| 输入 | pdf |
| 输出 | png / jpg / webp（渲染）、pptx、txt / md / html / docx（抽文字层）、pdf（图片合成 / 文字重排） |

五个模式：PDF 转图片、图片转 PDF、PDF 转 PPTX、PPTX 转 PDF、**PDF 转文本（1.4 新增）**。

### 3.6 音频

| | 格式 |
|---|---|
| 输入 | aac / flac / m4a / mp3 / ogg / opus / wav / wma（经 FFmpeg 解码） |
| 输出 | wav / m4a / aac 裸流 / mp3 / flac / ogg / opus / wma |

前三种走系统硬解（最快）；MP3 / FLAC / OGG / OPUS / WMA 由内置 FFmpeg 输出。**不支持**各音乐平台的加密格式（.ncm / .qmc / .kgg / .mflac 等），这些文件本身是加密容器，离线没有密钥解不开。

### 3.7 视频

| | 格式 |
|---|---|
| 输入 | mp4 / m4v / m4s / mkv / mov / avi / flv / wmv / webm / ts / mts / m2ts / mst（FFmpeg 全解） |
| 输出 | mp4 / webm / mkv / mov（换壳）、gif（动图）、jpg（抽帧）、mp3 / m4a / wav / flac / ogg / aac / opus / wma（音轨） |

- **MP4 / WebM 换壳**：系统 MediaMuxer 直接搬轨道；
- **MKV / MOV 换壳**：FFmpeg `-c copy`，容器不兼容时自动退回重编码并在界面写明；
- **GIF**：256 色全局调色板（palettegen + paletteuse + Sierra 抖动），支持帧率 / 宽度 / 起始时间 / 时长（≤60 秒）；
- **抽帧**：0.5 / 1 / 2 秒间隔导出 JPG，单次最多 60 张；
- **音轨导出**：8 种容器，只保留声音。

### 3.8 任意文件

`*` 全类型可选：选择器不过滤，选中后按真实类型分派到对应模块（乱码修复 / 图片 / 音频 / 视频 / 文档）。

## 四、视频模块细节

### 4.1 GIF 参数

| 参数 | 可选项 | 说明 |
|---|---|---|
| 帧率 | 8 / 10 / 12 / 15 / 20 / 24 帧每秒 | 越高越流畅，文件也越大 |
| 宽度 | 320 / 480 / 640 / 720 px | 高度按原比例，不放大小图 |
| 起始时间 | 秒，可填小数（如 12.5） | 留空 = 从 0 秒开始 |
| 时长 | 秒，最多 60 | 留空 = 取 3 秒 |

### 4.2 抽帧

按 0.5 / 1 / 2 秒间隔导出 JPG，长边超过 1920 自动缩小。系统解不了的封装会自动回退到 FFmpeg 抽帧。

## 五、PDF 模块细节

1. **PDF 转图片**：PNG / JPG，清晰度 2× / 3× / 4×，可填页码范围（如 `1-3,5`，留空为全部）。
2. **图片 转 PDF**：多选图片，页面尺寸可选"跟随图片 / A4 竖版 / A4 横版"。
3. **PDF 转 PPTX**：每页渲染成高清图，生成满版图片 PPTX（版式保真、文字不可编辑）。
4. **PPTX 转 PDF**：有整页图片就还原图片，纯文字则重新排版（标题加粗、正文按行折页）。
5. **PDF 转文本**：解析 PDF 内容流里的 `TJ` / `Tj` 文字指令，输出 TXT / Markdown / HTML / DOCX；扫描件、纯 CID 字体 PDF 没有文字层，会明确提示改用「PDF 转图片」。

## 七、已知限制（重要）

以下在「当前支持」图里出现过，但 v1.4 做不到，界面里也会写明：

1. **OCR 不提供**：离线没有 Tesseract / ML Kit 模型，「图片、扫描版 PDF 转 TXT」只在有文字层时有效。
2. **相机 RAW 不提供**：3fr / arw / cr2 / cr3 / crw / dng / nef / orf / raf / rw2 / srw / x3f / erf / fff / heic / heif / iiq / kdc / mef / mrw / pef 等依赖厂商解码库，APK 里没有。
3. **SVG / JXL / AVIF 编码**：不提供。FFmpeg 6.0 的 avif 解码可能可用（视设备），编码没有 libaom / libjxl，JXL 完全不支持。
4. **老二进制 Office 不提供**：`.doc / .wps / .wpt / .et / .ett / .dps / .dpt / .xls / .ofd / .mobi` 都是私有或复合二进制格式，离线解不开，请先另存为 docx / xlsx / pptx / epub。
5. **PDF → XLSX** 未实现：PDF 里的表格没有结构信息，抽出来只能是文字，硬塞进 xlsx 等于假数据，所以只提供 TXT / MD / HTML / DOCX。
6. **PPT → ODP / HTML / PNG / JPG** 未实现：PPTX 写入已有，ODP 与逐页导图没做。
7. PDF → PPTX 是图片版，文字不可编辑；PPTX → PDF 多图层、SmartArt、动画、母版装饰会简化。
8. GIF 单次最多 60 秒；帧率高于 20 时部分浏览器延时精度有限，可能有轻微变速。
9. 个别设备对特殊字体或加密 PDF 的渲染会失败，应用会给出明确报错。
10. 视频重编码较慢：10 分钟 1080p 约 1–4 分钟，H.265 / VP9 更慢。
11. 本项目没有真机测试环境，硬件相关路径靠代码审查 + 桌面 JVM 单测（乱码 21/21、GIF 3/3、PPTX 往返、字幕 6/6、PDF 抽文本、XLSX / ODT / DOCX / EPUB 生成与回读），仍有未覆盖的机型差异。
